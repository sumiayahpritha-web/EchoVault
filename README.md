EchoVault

EchoVault is a Java access control system designed to manage confidential digital resources using clearance levels.

Core Features

- Role-based access control
- Clearance-level validation
- Risk assessment logic
- Audit logging with unique request IDs
- Custom exception handling

OOP Concepts Applied

This project demonstrates several fundamental object-oriented concepts:

- Classes, Objects, and Constructors
- Encapsulation and Access Modifiers
- Abstraction and Interfaces
- Inheritance and Polymorphism
- Method Overloading
- Static variables and utility methods
- Custom Exception Handling

Clearance Levels

User Roles:
- Student: Level 1
- Researcher: Level 2
- Custodian: Level 3

Resource Access Requirements:
- Research Notes: Level 1
- Digital Instructions: Level 1
- Experiment Data: Level 2
- Encryption Keys: Level 3
- Confidential Archive: Level 3

Tech Stack

- Java
- VS Code
- Git and GitHub
